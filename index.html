01 — About

I build the boring, load-bearing parts well — auth, payments, sync, pipelines — so the interesting parts have somewhere to stand.

I started on Android at Bacancy, drifted into backend because that's where the hard bugs lived, and ended up comfortable across the whole line: a Kotlin screen, the Spring service behind it, the Go worker behind that, and the pipeline that ships all three.

At OneSpan I worked on the security end of that stack — secure storage and authentication for an SDK that banks put in front of millions of people. Nothing focuses you like code where a mistake is somebody's money.

Away from the editor I run a YouTube channel, shoot a lot of film and street photography, and cook for anyone who'll sit down. Same instinct, different medium: take something raw, pay attention, hand it to someone.
